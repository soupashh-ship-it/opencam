Discord & OBS Setup Guide

Method 1: OBS Virtual Camera (Recommended)

  1. Open OBS Studio → add Window Capture (select OpenCam Studio).
  2. Click Start Virtual Camera in OBS bottom-right panel.
  3. In Discord → Voice & Video, select OBS Virtual Camera!

Method 2: DroidCam Video

  1. Open DroidCam Client → connect to phone IP on port 4747.
  2. In Discord → Voice & Video, select DroidCam Video!
