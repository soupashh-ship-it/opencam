Simple 3-Minute Setup

Quick Setup Guides

Choose your preferred workflow to get streaming in seconds.

1

Install Phone App

Download and install OpenCam.apk on your Android phone. Launch the app and grant Camera/Mic permissions.

2

Install OBS Plugin

Install the standard open-source DroidCam OBS Plugin on your streaming PC.

3

Add Source & Stream

In OBS: Click Sources (+) → DroidCam OBS → Click Refresh → select OpenCam-... → Click Activate!

1

Launch PC Studio

Run the portable OpenCam Studio client on Windows (or run npm start from pc-client-native).

2

Scan Local Network

Click Scan Network to auto-detect your phone's IP address and port 4747 on the local Wi-Fi subnet.

3

Live Control & Preview

Enjoy ultra-low-latency desktop monitoring, instant snapshots, rotation flips, and bi-directional phone controls.

1

Enable USB Debugging

Go to Android Settings → Developer Options and toggle on USB Debugging.

2

Connect USB Cable

Plug your phone into your PC. The OBS plugin detects ADB devices automatically, or forward manually with one command:

adb forward tcp:4747 tcp:4747
3

Zero Interference Stream

Connect to 127.0.0.1:4747 in OBS or PC Studio for lightning-fast hardware throughput.

1

Register Virtual Cam

Run pc-client-native/vcam/register_vcam.bat as Administrator once (or click Enable Virtual Camera in OpenCam Studio).

2

Connect Phone Feed

Connect to your phone stream in OpenCam Studio. Live frames are automatically fed to the virtual camera ring buffer.

3

Select in WhatsApp / Teams

In WhatsApp Desktop, Teams, Discord, or Zoom: Select OpenCam Virtual Camera in your video settings!

Developer & Protocol Specs

Clean-Room Wire Protocol

OpenCam implements the high-performance DroidCam wire protocol over a single TCP port (4747 default).

REST Telemetry & Control API

GET /v1/status JSON telemetry snapshot (resolution, FPS, battery, zoom, lens, mirror, torch)
PUT /v1/settings?k=v Remote camera mutations (torch=1, zoom=2.0, lens=front, codec=jpg)
GET /v5/video/{codec}/{WxH}/... Binary framed video transport (H.264, HEVC, MJPEG)
GET /v2/audio 48 kHz AAC-LC synchronized audio transport
PUT /v1/tally/{program|preview|idle}/ OBS studio tally light feedback

12-Byte Binary Frame Structure

Bytes 0 – 7 (8 Bytes) Presentation Timestamp (PTS) Big-Endian (Microseconds µs)
Bytes 8 – 11 (4 Bytes) Payload Length Big-Endian Unsigned Integer
Bytes 12 – (12 + Length) Media Payload Raw H.264 / HEVC / MJPEG / AAC Buffer

PTS == 0xFFFFFFFFFFFFFFFF indicates codec SPS/PPS/VPS parameters.
Length == 0xFFFFFFFF represents the stream termination sentinel.
